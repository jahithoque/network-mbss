MBSS page templates

Seven pages: an overview, one page per platform (Check Point, BlueCoat, F5, Cisco IOS), an exceptions register and an automation backlog. Pick a page, press Copy page, and paste it into Confluence through Insert › Markup (Ctrl+Shift+D). Then type your rules into the Rule Register.

Confluence Data Center

Copy page
  1. Create the page and paste its title (Copy title).
  2. Click in the body and press Ctrl+Shift+D, or + › Markup.
  3. Leave Confluence wiki selected, paste, check the preview on the right, press Insert.

Status lozenges, panels, expands, Page Properties and the coverage report all arrive as real macros.

Page tree

    After pasting

    1. Create Network MBSS first, then create the other six pages as its children, using the page titles shown above.
    2. Add the labels shown under each title. The coverage dashboard on the overview lists every page labelled mbss-platform, so platform pages without that label won't appear.
    3. Delete the row marked EXAMPLE – delete once your first real rule is in. To add a row, press Tab in the last cell of the table.
    4. After you load the rules, update Total rules, Automated rules and Automation coverage in the Page Properties table at the top of the platform page. The dashboard picks them up automatically.
    5. The remediation snippets in Rule details are example syntax. Check them against your OS versions before anyone uses them.
