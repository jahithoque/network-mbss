Network MBSS · Confluence templates

MBSS page templates

Seven pages: an overview, one page per platform (Check Point, BlueCoat, F5, Cisco IOS), an exceptions register and an automation backlog. Pick a page, copy it in the format your Confluence accepts, paste it, then add your rules to the Rule Register.

Confluence Cloud

Copy for Confluence Cloud

Paste into a new page. Headings, tables, lists and code come across. Status values arrive as plain text, and the grey [Insert … macro] lines mark where to add macros with /toc, /page properties and /status.

Data Center / Server

Copy wiki markup

In the editor, open Insert (+) › Markup, choose Confluence wiki, and paste. Status lozenges, panels, expands and Page Properties come through as real macros. Use this on Cloud too if your editor offers Insert › Markup.

Source editor or REST API

Copy storage format

The most exact option. Paste into the source editor (Data Center, or the Source Editor app on Cloud), or send it as body.storage when you create the page through the REST API.

Page tree

    After pasting

    1. Create Network MBSS first, then create the other six pages as its children, using the page titles shown above.
    2. Add the labels shown under each title. The overview dashboard finds platform pages by the mbss-platform label.
    3. Delete the row marked EXAMPLE – delete once your first real rule is in. To add a row, press Tab in the last cell of the table.
    4. After you load the rules, update Total rules, Automated rules and Automation coverage in the page's properties table so the dashboard is correct.
    5. The remediation snippets in Rule details are example syntax. Check them against your OS versions before anyone uses them.
