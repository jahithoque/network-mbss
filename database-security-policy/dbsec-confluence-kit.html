Database Security Configuration Policy

Eight pages: the policy, one standard per database platform (Oracle, SQL Server, MySQL, MongoDB, Db2, Teradata) assessed with Tenable against CIS-based audit files, and an exceptions register. Pick a page, press Copy page, and paste it into Confluence through Insert › Markup (Ctrl+Shift+D).

Copy page
  1. Create the page and paste its title (Copy title).
  2. Click in the body and press Ctrl+Shift+D, or + › Markup.
  3. Leave Confluence wiki selected, paste, check the preview on the right, press Insert.

Status lozenges, panels, expands, Page Properties and the compliance report all arrive as real macros.

Page tree

    After pasting

    1. Create Database Security Configuration Policy first, then create the other seven pages as its children, using the page titles shown above.
    2. Add the labels shown under each title. The compliance dashboard on the policy page lists every page labelled dbsec-platform, so platform pages without that label won't appear.
    3. Fill the CIS Reference column from the reference field of the Tenable audit file version you scan with. To add a control, press Tab in the last cell of the register.
    4. After each Tenable scan, update Compliance % and Open CRITICAL / HIGH in the Page Properties table at the top of each platform page. The dashboard picks them up automatically.
    5. Queries and remediation snippets are examples. Check them against your database versions and apply changes through change management.
